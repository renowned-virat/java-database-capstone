## Admin User Stories
**Manage doctors profiles and get the statistical records for all:**
_As a Admin, I want 
Log into the portal with your username and password to manage the platform securely
Log out of the portal to protect system access
Add doctors to the portal
Delete doctor's profile from the portal
Run a stored procedure in MySQL CLI to get the number of appointments per month and track usage statistics, so that admin can have the visibility of all the works and can manage more efficiently._

**Acceptance Criteria:**
1. able to create and delete doctors profile
2. run procedure to get the appointments and track usage data .

## Patient User Stories

Log out of the portal to secure your account
